# pixiv AI メタデータスキャナー（ユーザースクリプト）

**日本語** · **[中文](README.md)** · **[English](README.en.md)**

pixiv 上で、どの画像が AI 生成なのかを一目で分かるようにハイライト表示します。マウスオーバーするだけで、完全なプロンプト・生成パラメータ・ComfyUI ワークフローを確認でき、ワンクリックで書き出して再現できます。ComfyUI / Stable Diffusion / NovelAI に対応しています。

> ご利用の前に、末尾の[免責事項](#免責事項)をお読みください。

## 機能

- **手動スキャン**：ページ右上の「AI 扫描」（AI スキャン）ボタンをクリックすると、現在のページ（作家ページ / 検索結果 / ブックマーク / 作品詳細ページ）の作品サムネイルをすべて列挙してスキャンします
- **AI メタデータの抽出**:
  - **ComfyUI** → `prompt` / `workflow`（ワークフロー JSON。ComfyUI にそのままドラッグ&ドロップして再現できます）
  - **Stable Diffusion (A1111/Forge)** → `parameters`（prompt / negative / seed / sampler / CFG / model）
  - **NovelAI** → `Comment`
- **高速**：HTTP `Range` ヘッダーで PNG のヘッダー（約 256 KB）だけを取得してテキストチャンクを解析し、元画像の全体はダウンロードしません
- **レート制限**：同時実行数 4、4 req/s、429 時は 30 秒の適応型バックオフ、リトライ、項目ごとのハードタイムアウト
- **UI**:
  - メタデータを持つサムネイル → **緑の枠 + 種類バッジ**（ComfyUI / SD / NovelAI）
  - 画像ごとのスキャン状態
  - **ページ全体の一括プログレスバー**（スキャン済み X/Y · AI 画像 N 枚 · パーセント）
  - サムネイルにマウスオーバー → プロンプト / パラメータ / ワークフローを表示
  - ComfyUI ワークフロー JSON の**コピー / ダウンロード**をワンクリック
- **API フォールバック**：組み立てた元画像 URL が使えない場合は、pixiv API から正式な URL を取得して再スキャンするため、取りこぼしがありません

## インストール

1. ユーザースクリプトマネージャー（Tampermonkey / Violentmonkey）をインストールします
2. `pixiv-ai-metadata-scanner.user.js` を開いて新規スクリプトとしてインポートします（Greasyfork / GitHub から直接インストールすることもできます）
3. 任意の pixiv ページ（作家ページ / 検索 / ブックマーク / 作品詳細）を開き、**右上の「AI 扫描」ボタンをクリック**してスキャンを開始します（自動ではスキャンしません）

## 開発

```bash
npm install        # esbuild をインストール
npm test           # ユニットテストを実行（PNG 解析 / pixiv URL / スキャンエンジン）
npm run build      # 単一のユーザースクリプトにバンドル
```

## ディレクトリ構成

```
src/
├── png.js         PNG テキストチャンクの解析（tEXt/iTXt/zTXt、zlib 展開を含む）
├── metadata.js    AI メタデータの判定と抽出（ComfyUI/SD/NovelAI）
├── pixiv.js       pixiv 対応：リンク方式での作品列挙、サムネイル→元画像 URL、API フォールバック
├── scanner.js     一括スキャンエンジン（同時実行 / レート制限 / 429 バックオフ / キャッシュ / リトライ / 進捗）
├── transport.js   GM_xmlhttpRequest + Range + referer で PNG ヘッダーを取得
├── ui.js          UI：緑の枠 / 種類バッジ / スキャン状態 / ページ全体のプログレスバー / サイズ変更できるパネル / ワークフローの書き出し
└── main.js        エントリポイント。各モジュールを組み立てる
test/              ユニットテスト
scripts/build.js   ビルドスクリプト（esbuild + ユーザースクリプトヘッダー）
```

## 未実装の機能

- **ステガノグラフィ系のメタデータ**：一部の NovelAI（stealth_pngcomp）や SD Forge は、メタデータをピクセルの最下位ビットに隠しています。読み出すには画像全体をデコードする必要があります。現在のバージョンは PNG のテキストチャンクしか読まないため、この種の画像は判別できません。
- **PNG 以外の元画像**：解析するのは PNG のみです。jpg / webp の元画像もテキストチャンクのメタデータを持たないため、対象外です。
- **pixiv 以外のサイト**：現時点では pixiv のみに対応しています。

## 謝辞

本スクリプトは独立した実装です。以下のプロジェクトのコードは使用していませんが、設計の考え方とメタデータ形式の判定において参考にしています：

- [pixiv-metadata-viewer](https://github.com/da2el-ai/pixiv-metadata-viewer)（da2el-ai）— 参考にした点：PNG に埋め込まれたメタデータから AI 画像を判定する考え方、`parameters` / `Comment` フィールドの解析、NovelAI v4 `char_captions` の扱い
- [Pixiv Downloader](https://github.com/drunkg00se/Pixiv-Downloader)（drunkg00se）— 参考にした点：`<a href>` + 構造ホワイトリストによる作品の列挙（「二重ゲート」）
